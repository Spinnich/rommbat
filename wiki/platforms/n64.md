## Which emulator to use

Leave RetroBat on its default, RetroArch with the Mupen64Plus-Next core. Every emulator RetroBat
offers for the Nintendo 64 passed RomMBat's tests, so any of them is safe to pick, with the
Controller Pak setting below.

## BIOS

The Nintendo 64 needs none, and RetroBat lists none. Every emulator starts a game without one.

## Saves

A save follows you to another emulator only where the two read the same file
([Changing emulator](../saves/index.md#changing-emulator)). On the Nintendo 64:

- RetroArch's Mupen64Plus-Next and ParaLLEl N64 cores share one save.
- Rosalie's Mupen GUI (`mupen64`) and simple64 share another.

The rest each keep their own, and each emulator stores a game's save in its own format.

### The Controller Pak

**Four emulators start with no Controller Pak plugged in**: RetroArch's ParaLLEl N64 core,
Rosalie's Mupen GUI, and BizHawk's Ares64 and Mupen64Plus cores. A game that saves to the pak,
such as Mario Kart 64's ghosts, saves nothing there until you plug one in. Set P1 Controller
Extension to Memory, or Memory Pack, in the system's settings (Game settings, then Per system
advanced configuration). RomMBat syncs the pak with the game's save.

## Known issues

A game that saves to FlashRAM, one of the kinds of cartridge save, has not been tested, and on
every emulator but RetroArch's two cores its save does not sync yet. Those two keep every kind of
save in one file, which syncs.
