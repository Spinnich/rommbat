# Nintendo Entertainment System

|                 |                                                                     |
| --------------- | ------------------------------------------------------------------- |
| RetroBat system | `nes`                                                               |
| Games go in     | `roms\nes`                                                          |
| BIOS            | None                                                                |
| Tested rows     | [Platforms](index.md#nes) lists each emulator and whether it passed |

## Which emulator to use

Leave RetroBat on its default, RetroArch with the FCEUmm core. Every emulator RetroBat offers
for the NES passed RomMBat's tests, so any of them is safe to pick.

## BIOS

The NES needs none, and RetroBat lists none.

## Saves

A save follows you to another emulator only where the two read the same file
([Changing emulator](../saves/index.md#changing-emulator)). On the NES:

- RetroArch's FCEUmm, Nestopia and Mesen cores share one save.
- The standalone Mesen and Mednafen share another.
- BizHawk's two cores share a third.

The rest each keep their own.
